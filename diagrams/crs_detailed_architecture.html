Recommendation with transparent evidence & caveats

1. Preference Parser & Router

Hard constraints: price, brand include / exclude, category. Soft preferences: value + polarity; attributes the catalog cannot filter on are demoted here.

Router actions: SEARCH · CLARIFY · UPDATE_PROFILE · READ_PROFILE · ANSWER.

R2a: head noun of requested product = category. Guardrail: SEARCH without category → recovery call, accepted only if product_type_decided is true, else CLARIFY. Override: category + brand → SEARCH.

2. Multi-Index Retrieval & Graph v2

R1: Each product once per channel by best match, fused by RRF (k = 60).

Graph v2 (GV2-01..04): 13,018 products, 0 ghost nodes, 99.995% review coverage sorted by helpful_vote DESC per product (AI-06). Multi-value brands/categories list filters (GV2-03) and deduplicated soft-preference bonuses across unit variations (GV2-04).

MACS: yield < 3 → widen budget ceiling/floor by 15%, then drop category.

3. Critic & KECR Reasoning

Critic (GV2-01/05): evaluates candidate price, brand, category AND Graph v2 features, technical details, description, rating. Fail-closed on error (is_recommended=false). When all 20 rejected, falls back to top-3 partial matches with Critic rejection caveats.

KECR (GV2-06): deterministic Cypher graph evidence path extraction; conversational match and honest fallback without fabricated 5.0★ rating.

Historical & co-purchase paths inactive on live graph (schema mismatch · AI-03).

4. Explainable Synthesis & Roadmap

Synthesis (GV2-01/05): Prompt constructor injects rich features, catalog avg_rating, [RELAXED CONSTRAINTS], and partial match status. LLM transparently discloses trade-offs and unverified constraints.

R1/R2a: per-channel ranks, clarify_reason, category_resolution in eval_trace; citable runs in evaluations_archive/.

Roadmap: Graph v2 Stage 0 done · R2b benchmark v2 · Stage 1 Taxon & Lexical RRF channel · R3 search order · R4 feature fit & LLM judge.
